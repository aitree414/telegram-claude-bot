# 08 Collective — AI 工具包

## 已建立的能力

### 1. 08-Collective Skill（已註冊）
當你提到 08 Collective 相關工作時，我自動載入你的公司背景、文件標準、客戶資訊，確保產出符合你的格式。

### 2. 文件自動生成

| 工具 | 說明 | 使用方式 |
|------|------|---------|
| **報價單** | XLSX + PDF 成對輸出，08格式 | 提供項目清單，我直接生成 |
| **製作圖** | Blueprint 風格 SVG 工程圖 | 描述需求，我產出視圖+尺寸+BOM |
| **工作進度表** | HTML + XLSX 格式 | 給時間和任務，自動排程 |
| **攤位配置圖** | 平面圖 + 設備清單 | 給場地尺寸，自動配置 |

### 3. 可以幫你的日常事項

**報價相關：**
- 從需求表（Excel）自動生成報價單 XLSX + PDF
- 報價版本管理（v1→v7+），標示每次修改
- 不同客戶格式（HKDC、香港文聯、PolyU 等各有不同要求）

**製作圖相關：**
- 木作生產圖（YONEX 那種）
- Truss/結構工程圖
- 展位平面配置圖
- 活動場地 layout

**投標文件：**
- Technical Proposal 架構協助
- Fee Breakdown 自動計算
- 文件排版

**進度管理：**
- 施工 timeline 自動生成
- Load-in → Assembly → Show → Strike 各階段

## 使用入口

- 「畫 XX 的製作圖，尺寸是...」
